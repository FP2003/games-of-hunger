# Gameplay request completion audit

The scope is the original request plus the later clarification to use the existing regions. The arena must keep its six regions; the earlier suggestion to add a region was withdrawn. Work was delivered in batches of one or two requested points.

Current source: content 1.18.0, engine 1.14.0. The pack contains 574 event templates, 66 interview templates, eighteen trait choices and the original six biome IDs and adjacency graph. Wording variants are not counted as separate events.

## Generated story evidence

`node scripts/gameplay-audit.mjs` bundles the current source and runs sixteen seeded 24-player games: eight neutral casts and eight casts with the new traits, alternating Normal and High danger. It regenerates `examples/gameplay-audit.json` and the final wording review. All recorded runs pass engine replay validation before the audit examines their events.

The current artifact records 323 simple departures, including 133 grouped departures and 75 grouped bloodbath exits. The longest sampled simple departure is 21 words using the sample names. It records 38 actual ration/water consumptions, 23 blanket uses and fourteen sourced death callbacks. There are no audit violations for excessive simple-travel length, split party destinations, repeated retained staple creation or unsupported callback sources.

The rock/stone field is a conservative text-mention count, including natural falls onto rocks; it is not a claim about the precise cause of every death. The sample is evidence of observed behavior, not a guarantee that every rare event or trait scene appears in every game. Direct gated-outcome tests cover those cases separately.

## Compatibility and verification

New effects, trait choices and optional interview applicability filters are schema-validated. Older input snapshots lack the new optional fields and retain their original content and saved prose. Existing replay identity, archive, persistence, pronoun, relationship, one-assignment-per-phase and one-survivor checks remain part of the complete regression suite.

Final verification results are recorded in `docs/GAMEPLAY_IMPROVEMENTS.md`. Required checks are the complete unit/content/engine/persistence suite, production build with type checking, the complete desktop/mobile browser suite, generated gameplay audit and `git diff --check`.
