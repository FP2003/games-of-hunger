# Engine behavior (version 1.16.0)

`generateRun(input, narrative)` validates and snapshots the input and returns a complete deterministic replay. The UI reveals snapshots using its own cursor. This module has no browser, storage or React dependency.

- Randomness is xmur3-seeded mulberry32. Mechanics, wording, confessionals, arena changes and scheduled recipient shuffling use independent named streams; event-effect movement uses a deterministic stream derived from seed, sequence, template and bindings. Editing text variants cannot change mechanical choices.
- The default narrator excludes each template's last-used raw wording from its next selection when another distinct version exists, for both events and interviews. Event wording then favors the least-used alternatives across all template IDs, so shared regional prose uses the same memory and unused situations go first. The engine owns separate per-run memories, shared across speakers/bindings, and resets them for a new game. Adapters receive optional previous wording and transient `wordingUses` counts and return optional `wording` metadata; only rendered text is saved. Single-version custom templates remain valid. This memory never alters event eligibility or mechanical randomness.
- Interviews also receive `usedTexts`: all previously spoken rendered interviews in the run, shared across speakers and templates. The default narrator excludes those lines permanently for that run. If the appropriate pool is exhausted or on cooldown it returns no interview, rather than repeating a line or reacting to an incidental fact. Selection prioritizes the main consequence (death, revenge, betrayal, grudge, theft, curse, alliance, assistance, acquisition, movement), then trait-specific reactions. This does not change event eligibility, outcomes or inventory.
- Relationship-only tool-assisted scenes resolve `{item}` from the declared held-item role or condition when no committed item fact/effect identifies it. Resolution uses the actual instance label and holder, never an unrelated inventory item. Version 1.10.0 records this wording fix; existing replay text stays unchanged.
- Ten local group cooperation scenes bind three or four distinct available living tributes. Four rescues bind a helper (`actor`), escapee (`target`) and named `pursuer`; assistance credits the helper, the escapee resents the pursuer, and the pursuer resents the intervention. All survive. Non-hostile trust gates apply to cooperating partners; the pursuer must not trust the escapee positively, and Loyal hostility rules still apply. Food/water groups create one real supply per participant. The injured escort requires and clears an actual bleeding-thigh marker and credits both helpers. These scenes use ordinary assignments and do not grant persistent protection or new health stats.
- Assistance/alliance interviews require the speaker to be a credited helper or beneficiary of a matching fact. Merely being present as a named pursuer does not qualify for a positive cooperation reaction.
- Everyone begins alive in the Center Podium. Signature labels become ordinary unique instances. No previous-season runtime state or relationships are copied into the next season.
- The default bloodbath includes shared escapes into each outer region, a solo escape option, central supply collection, and lethal contests awarding two supplies to the survivor. Shared exits bind two unassigned tributes, record mutual assistance, and move both to the same region. Cautious anchors favor escape; reckless anchors favor the centre when personality effects are enabled.
- Default ordinary encounters share a region. Low-weight border encounters require adjacent starting regions and move the actor into the target's region before assistance or elimination. Separated finalists move along explicit routes back to the Center Podium before their confrontation.
- Low-weight sponsor templates deliver rations, water or blankets through ordinary item creation during days/nights, with a four-phase template cooldown. Gifts persist in inventory and follow the same transfer/drop rules as other items.
- Biome advantages and drawbacks are small background selection weights, without visible stats. Weather and closures use an independent seeded arena stream and optional snapshotted biome state; old replays without it still validate under their recorded engine version.
- Arena announcements bind no contestants, consume no assignments and have no confessionals. Day 2 can warn of temporary weather; later days can warn of permanent nightfall closures. A warning precedes onset by one phase. Temporary weather clears the following phase. Each occupied outer biome is warned at most once, with at most three disruptions per game. The Center Podium stays open. Evacuating residents use their ordinary assignment to escape or die of the named hazard; supplies, enabled traits and untreated bleeding influence risk. Closure commits only when the region is empty of living tributes, and all movement including curses rejects closed/evacuating destinations.
- Rare authored multikills require local distinct participants and minimum survivor counts, start after Day 1, and pass an additional 6% eligibility gate before weighted selection. At most one occurs per default run. Each victim receives a separate credited elimination fact; kill awards count victims, while evidence references stay unique.
- Opening is followed by alternating days/nights. Every phase samples an unassigned living anchor, then binds distinct unassigned living roles. Local roles share a biome. Partial condition pruning limits each template search to 3,000 visits. Candidate ordering and tie breaks use stable string ordering.
- Template weights are positive. Lethal templates receive danger multipliers 0.55/1/2.6 and a gradual day multiplier capped at 5. Matching tone gets 1.6. General trait boosts cap at 1.6 (normal) or 2.2 (strong), with additional targeted relationship biases. Traits never ensure survival.
- Recent-template suppression relaxes first; phase cooldowns relax second; hard eligibility never relaxes. An original quiet fallback handles empty ordinary eligibility. At two survivors, or at the start of Day 8, finale events must eliminate someone. All final bouts stay on the day the finale began; separate phase indices preserve the one-assignment-per-round rule without advancing the calendar. A visible boundary fallback eliminates one person when no authored finale fits. Victory is checked after every event, so even an impossible custom pack finishes by Day 8.
- Effects apply to a cloned transaction. Invalid ownership, markers, movement, references, unsupported effects or elimination of everyone reject the entire event. Items have one authoritative `ownerId`; elimination drops possessions in the victim's biome.
- Relationships clamp trust to -100…100 and grudge to 0…100. Theft changes the former owner's opinion by -35/+45. Reciprocal trust of at least 40 forms an alliance. The highest outgoing living grudge of at least 40 defines a nemesis; equal grudges use player ID.
- Relationship assistance/betrayal effects update the affected player's opinion (`from`) of the helper/betrayer (`to`); facts credit `to` as actor. Alliance and revenge effects use `from` as actor. Revenge needs a recorded earlier hostile act; its fact retains that source event. Credited elimination can also settle an earlier theft/betrayal.
- Legacy/custom-pack support: the compass curse moves its current owner to an adjacent biome. A held bell multiplies encounter/conflict weights by 1.8; destroying or losing it removes that influence. Explicit tin activation decreases its owner's trust of another bound participant by 30 and adds 30 grudge. Tin transfers additionally decrease the former owner's trust by 25 and add 25 grudge. Activations and their consequences produce facts.
- Declared phase markers expire at phase boundaries. Player-valued markers resolve role IDs to player IDs and are removed when their target is eliminated. Content chains declare their own progress/reset effects.
- Default survived stab attacks record the injured site with season-long bleeding markers and adjust trust/grudge toward the attacker. Treatment scenes require and clear the matching marker; assistance credits the helper. These are authored branches using existing markers, not a health or automatic damage system. Fatal scenes and the boundary fallback explain the physical cause of death in their saved prose.
- Confessionals have a 30% chance per contestant event, capped at four total per assignment round (phase index) and one per speaker. The chance uses the independent confessional random stream, so interview availability never changes mechanics. Only a just-eliminated participant can give an exit interview. One relevant historical callback per run receives structured source references; lore disabled normalizes the context to empty.
- Simultaneous eliminations tie at survivors remaining plus one. Count-based awards share exact ties and omit zero-evidence categories. Recaps and awards use recorded events/facts rather than searching prose.

- Expanded personality rules live in `personality.ts`: Loyal blocks betrayal and deliberate hostility against mutual allies during binding and effect validation; Disloyal biases the acting betrayer. Love and Hate initializes extreme seeded outgoing attitudes and doubles subsequent reactions. Grudge records a killed ally and credited killer, retains resentment through later changes, and enables validated revenge callbacks to the death event.
- Agile, Weak Constitution and Perceptive use authored scene gates and bounded environmental risk, without numeric player attributes. Personality Off excludes trait-only templates and disables all personality weights, relationship rules and risk changes.

- New casts and generated runs allow at most two positive traits (Loyal, Sneaky, Cautious, Resourceful, Agile, Perceptive, Tracker, Medic, Patient, Early Riser, Night Owl, On Guard, Forest-wise). Older replay inputs retain their choices; stored cast reads preserve over-limit selections for explicit editing.
- Agile shortcuts can create a season-long `sprained-ankle` marker. Agile role/condition gates and its evacuation bonus stay suspended until a recovery scene removes the marker. Ordinary escapes and trap spotting remain eligible. Perceptive investigations consume the normal phase assignment without movement or new supplies.

- Scheduled content scenes run once per schedule group from their configured day, use normal tribute assignments, and stay out of random encounter selection. Eligible recipients are shuffled without replacement using the dedicated `scheduled` seeded stream. Templates retain ID-order precedence, so the resident resupply is tried before the arrival version. The default Center Podium resupply starts on Day 3, gives a tribute rations and leaves water and a blanket on the ground; a tribute from an outer region follows an explicit adjacent route if the podium is empty. The internal biome ID remains `ruins` for replay compatibility.

- Supply absence conditions (`item` with `exists: false`) are hard gates; omitted `exists` retains the original ownership requirement. `consumeItem` depletes a held supply, keeps its retired instance in snapshots, and emits `consume` rather than `destroy`. Reusing it fails atomically. Default acquisition balance and supply-use scenes live in content; custom packs keep their authored policies.
- Exact-site death memory uses explicit optional template `site` metadata, keyed by site ID plus biome. After a death commits, `site-memory.ts` finds the most recent matching earlier death and records `site-revisit` with its source sequence and victims. Optional narrative `history` supplies the recorded evidence for seven factual callbacks. Run validation rejects invented or mismatched source references. Neither prose matching nor cross-season lore can supply a same-site death.

- Ordinary movement policy is opt-in through template `travel` metadata. Warned residents, active-weather residents, then players with three ordinary non-moving assignments are chosen as anchors before routine encounters. A matching legal departure takes that ordinary assignment and bypasses template-recency suppression. Evacuation, scheduled scenes, opening and finale retain their existing ordering. No movement counter is persisted: the policy derives residence from recorded assignments and movement facts, counting every bound participant.
- `avoidDanger: true` on an adjacent move selects the lowest-risk enterable neighbors before seeded choice: open, weather-warning, hazardous, closure-warning. Explicit destinations and compass curses retain their existing behavior. Closed/evacuating destinations remain invalid and held equipment follows the move.

- Selection binds and weights eligible options before applying effects. A selected invalid transaction is discarded and selection retries among the remaining options, preserving weighted choice among valid encounters while avoiding a full state clone for every unused option. Required departures search only matching travel scenes first; normal encounter selection remains the fallback if no legal departure commits.

- Group travel uses `moveGroup`: all declared roles must be distinct living local players; a single legal destination is chosen, then every player and owned item moves there atomically. Facts stay as individual `move` records. Default ordinary parties contain only unassigned residents with the same requested departure reason and nonnegative reciprocal trust. The largest eligible party up to four goes first; others retain their own assignments.
- `trait-expansion.ts` applies Tracker, Medic, Patient, Loud, Clumsy and Gullible selection biases with actor/victim ownership preserved. Tracking and clumsiness also affect bounded evacuation risk. New scenario gates and optional interview `eventIds` filters prevent unsupported trait actions and medical/scam quotations on unrelated events. Personality Off disables the new effects and trait-only scenes.


- DD-inspired preferences live in `quirks.ts`. Optional template `behaviors` metadata binds each action to a declared role. Generic default scenes derive tags from explicit inventory, movement and relationship effects; standalone quirk scenes author tags directly. Untagged custom templates receive no semantic bias. Early Riser uses day foraging/travel, Night Owl uses night scouting/concealment/travel, On Guard uses opening escapes/guarded supplies, and Forest-wise uses forest foraging/travel. Kleptomaniac favors the thief, Curious favors risky inspections, and Compulsive Eater favors actual ration consumption.
- New quirk preferences use 1.2x/1.4x at Normal/Strong. Unlit ordinary solo travel gets 0.85x/0.7x for Afraid of the Dark. The combined new multiplier clamps to 0.7–1.5 / 0.5–1.8 before existing environmental modifiers. These are selection weights, not survival probabilities. There are no new evacuation-risk or finale bonuses. Arena/scheduled scenes bypass the new weights; required movement retains priority. A held, undestroyed `lantern` suppresses fear scenes and modifiers immediately, including after transfers.
- Trait scenes consume ordinary assignments. Theft transfers a real item and changes the victim's opinion; Loyal blocks theft from mutual allies. Compulsive eating consumes one held ration without recovery or protection. Curiosity has separate acquisition, empty inspection and nonfatal shoulder-bleeding scenes. Trait interviews require the specific scene and an actor-compatible fact. Transient `personalityEnabled: false` excludes trait interviews with Personality Off; saved replay data does not gain a new field.
- Content 1.23 removes cursed definitions, their encounter paths and curse-only interviews from the new default pack. The oil lantern retains ID `lantern`. Curse schemas/effects and bell weighting remain supported for saved snapshots and custom packs. Engine 1.15.0 replay fixtures verify portable export/import, memory/IndexedDB persistence and recorded story playback without content substitution.
